# ExiEngine güvenlik modeli

## Tehdit sınırı

Motor; oyun asset’i, atlas JSON’u, save verisi ve pointer/keyboard girdisini güvenilmeyen sınır olarak kabul eder. Oyun kodu ise uygulama sahibinin aynı JavaScript realm’inde çalışır; ExiEngine bunu sandbox olarak vaat etmez.

## Varsayılanlar

1. Asset URL’leri constructor’da alınan base/origin snapshot’ı ile aynı origin ile sınırlıdır. Farklı origin ancak açık `allowedOrigins` seçimiyle eklenebilir; public `baseURL` veya allowlist mutasyonu resolver’a girmeden reddedilir.
2. Asset response byte sayısı, image boyutu ve atlas frame sayısı limitlidir.
3. Renderer GPU texture toplam byte/sayı bütçesi uygular; atlas subtexture’ları tek `baseTexture` kaynağı olarak sayılır.
4. Redirect, data URL ve desteklenmeyen protokoller reddedilir.
4. Shader ve WGSL metni kullanıcı/asset verisinden oluşturulmaz.
5. Save verisi yalnızca JSON olarak saklanır; namespace 64, key adı 128 karakterle ve değer byte boyutuyla sınırlıdır. `maxBytes` 16 MiB mutlak tavana bağlıdır; set/get JSON derinliği 64 ve kaba node/token bütçesi 100.000 ile `JSON.parse()` öncesi sınırlandırılır, doğrudan public `maxBytes` yükseltmesi reddedilir.
6. Pointer capture/cancel, görünürlük ve `pagehide` geçişleri, takılı keyboard/pointer/gamepad state’lerini temizler.
7. Input action adları, binding sayısı, ham keyboard state’i ve klavye/gamepad indeksleri sınırlandırılır; action binding’leri veri olarak kalır ve callback/eval/script çalıştırmaz. Gamepad hot-plug callback’leri yalnızca motorun 128 karakter ID, 32 axis ve 64 button sınırları uygulanmış snapshot’ını verir. `Input.destroy()` idempotenttir ve teardown sonrasında geç gelen native callback’ler input state map’lerini yeniden oluşturamaz.
8. Gamepad index’i 0..15, ID’si 128, axis sayısı 32 ve button sayısı 64 ile sınırlandırılır; axis değerleri `[-1, 1]` aralığına clamp edilir, snapshot dizileri bu kapasite içinde yeniden kullanılır ve bağlantı kopması bir frame içinde basılı tuşları güvenli biçimde bırakır.
8a. Input axis adları ve toplam action/axis binding koleksiyonu 256, binding sayısı 8 ile sınırlıdır. `deadzone` 0..0.99, `scale` -1..1 ve sonuç -1..1 aralığında clamp edilir; analog input sınırsız aritmetik veya koleksiyon büyümesi oluşturamaz. Public runtime Map’leri doğrudan değiştirilse bile `getAxis()`/action sorguları ve snapshot yolları bu kapasiteyi yeniden doğrular.
8b. Ham keyboard state’i 256 key ile sınırlıdır; 64 karakterden uzun/boş code ve bilinmeyen keyup event’leri Set’lere yazılmaz.
8c. `Input.setBindings()` action/axis adlarını, binding türlerini, her map’in 8 binding ve toplam 256 kayıt sınırını mevcut normalize fonksiyonlarıyla doğrular; çakışma veya geçersiz kayıt varsa map’ler atomik olarak değiştirilmez. `getBindings()` yalnızca derin kopya döndürür; snapshot değişikliği canlı input state’ini değiştiremez.
8d. `Input.rumbleGamepad()` yalnızca 0..15 gamepad index’ine erişir; duration 10 saniye, strong/weak magnitude 0..1 ile sınırlıdır. Native `dual-rumble` veya legacy `pulse` actuator yoksa `false` döner, haptic exception oyun input akışını bozmaz ve native Gamepad nesnesi snapshot API’sine sızmaz. `beginFrame()`/`endFrame()`/pointer snapshot yolları public state Map/Set taşmasını da tüketim öncesi reddeder.
9. Pointer handler’lar yalnızca oyun kodunun açıkça verdiği callback’lerdir; asset verisi handler kaydedemez. Primary pointer down hedefi scene hit-test ile capture edilir, up/cancel aynı hedefe gönderilir, move/enter/leave yalnızca görünür hit-test hedeflerine gider. Down/up/move/cancel/wheel olayları parent zincirine mevcut scene graph depth’i kadar bubble eder; `pointerenter`/`pointerleave` etmez. Event nesnesi transient olarak yeniden kullanılır; `stopPropagation()` yalnızca mevcut dispatch’i keser, kullanıcı callback’i veya asset kodu çalıştırmaz.
10. Demo sunucusu loopback’e bağlanır; yalnızca engine/game için gereken allowlisted web uzantılarını servis eder, gizli/dot dosyaları ve dependency lock metadata’sını `404` ile gizler; path traversal çözülmüş yol workspace dışındaysa `400` döner.
11. `npm test` içindeki server smoke, gerçek HTTP istekleriyle CSP, `nosniff`, CORP, referrer/cache başlıklarını, `HEAD`/method davranışını, 404’ü ve encoded path traversal reddini doğrular.
12. `npm run verify`, statik güvenlik taraması, HTTP smoke, engine smoke ve tüm allocation/streaming benchmarklarını tek release kapısında yeniden çalıştırır; browser/cihaz kanıtı ayrıca gereklidir.
13. `Node.add()` toplu reparenting sırasında önce tüm node türü, cycle ve duplicate kontrollerini yapar; doğrulama hatası kısmi scene graph mutasyonu bırakmaz.
14. `tools/exi-mcp-server.mjs` yalnızca sabit `src/index.js` export yüzeyini açar; MCP JSON-RPC mesajları 1 MiB, string’ler 64 KiB, tool çıktıları 64 KiB, binary argümanlar 512 KiB, JSON değerleri derinlik/alan/öğe, scene graph 1.024 node/32 depth, batch 128 call ve handle tablosu 4.096 kayıtla sınırlıdır. A* yalnızca bounded typed-array/heap üzerinde çalışır, grid’i değiştirmez, callback veya script çalıştırmaz ve limitte `truncated:true` ile kontrollü döner. Bu, MCP’den gelen büyük veya kötü biçimli navigasyon verisinin sınırsız CPU/bellek işine dönüşmesini önler.

MCP result/inspect/session-status ve browser `RuntimeAgent` serileştirmesi nesne türü ve destroyable metadata’sı için prototype data descriptor’larını kullanır; `constructor` veya `destroy` accessor’larını normal property erişimiyle çalıştırmaz. Değer getter’ları yalnızca açıkça `exi_get`, `exi_export_get` veya ilgili public çağrı istendiğinde değerlendirilir.

MCP `exi_scaffold` yalnızca `EXI_MCP_ROOT`/repo kökü altında göreli dosya yazabilir, engine/test/tool köklerini, traversal/absolute path ve symlink’i reddeder, tüm starter dosyalarını önce benzersiz geçici dosyalara stage eder ve çok dosyalı commit yarıda kalırsa yeni dosyaları geri alıp backup’ları restore etmeye çalışır; mevcut dosyaları `overwrite=true` olmadan ezmez. `exi_project_open` mevcut klasörü aynı kök, symlink ve engine/test/tool kontrollerinden geçirir; kontrol edilebilir HTML/JS/JSON dosyalarını kod çalıştırmadan statik kontrol eder, böyle bir dosyası olmayan projeyi session scope’una almaz ve kontrol hatası olursa scope kaydını bırakır. `exi_file_list`/`exi_file_read`/`exi_file_write` yalnızca aynı session’da scaffold edilen veya `exi_project_open` ile açılan proje klasörlerine, allowlisted text uzantılarına ve symlink olmayan path’lere erişir; tek çağrılı text yazma 64 KiB, chunked text dosyası 4 MiB, chunk 48 KiB, bekleyen toplam 16 MiB ve aktif transfer 8 ile sınırlıdır. Büyük okumalar UTF-8 sınırlarını koruyan 48 KiB sayfalara ayrılır. Listeleme 1.024 dosya/32 klasör derinliği ile sınırlıdır, eksik parent klasörleri yalnızca proje scope’u içinde oluşturulur, `.env`/credential ve binary dosyalar reddedilir. ## Bilinçli olarak yapılmayanlar

MCP bridge ve browser `RuntimeAgent` typed-array/`DataView` çıktılarında inline byte payload’ını `maxInlineBinaryBytes=32 KiB` ile sınırlar; daha büyük değerler yalnızca `truncated` metadata’sı taşır. Bu sınır genel tool/runtime result limitlerine eklenir ve binary input’un 512 KiB sınırını yükseltmez. BigInt typed-array sample değerleri string’e çevrilerek JSON serileştirme hatası engellenir.

- Asset içindeki script, WASM veya executable içerik çalıştırılmaz.
- Kullanıcı shader’ı, HTML template’i veya arbitrary JavaScript motor API’si yoktur.
- Audio ve image loader uzak origin güvenini kendiliğinden genişletmez.
- Production kimlik doğrulaması, CDN imza doğrulaması ve servis-worker izolasyonu motorun görev alanı değildir; dağıtım katmanında yapılmalıdır.
- MCP istemci kimlik doğrulaması, kullanıcı/agent yetkilendirmesi ve process izolasyonu motorun görev alanı değildir; bridge’i yalnızca güvenilen local agent’a bağlayın ve üretim ortamında OS/container izinleriyle ayrıca sınırlandırın.

## Text cache güvenliği

`ParticleEmitter.maxParticles` 100.000 kayıtla mutlak olarak sınırlandırılır; emit/update/render/instance girişleri oluşturulan typed-array kapasitesini ve public `particles`/`maxParticles` mutasyonunu O(1) doğrular, kontrolsüz typed-array veya CPU render işi reddedilir.

Particle rate, lifetime, size, koordinat, hız, ivme ve delta değerleri sınırlı finite aralıkta tutulur; geçersiz random callback’i varsayılan rastgele kaynağa döner ve `Infinity` simülasyon adımı state’i bozmaz. Ölen particle kayıtları `maxParticles` sınırını aşmayan object pool’da yeniden kullanılır; input kaynaklı churn sınırsız object büyümesine dönüşmez.

Engine viewport boyutu, CSS/DPR resize sonrasında da 16.384 piksel ile, `fixedStep` 1 saniye ile ve frame delta 5 saniye ile sınırlandırılır; sonsuz/NaN konfigürasyon değerleri güvenli varsayılanlara döner.
`ExiEngine` çalışma konfigürasyonunun public `width`/`height`/`resizeMode`, `maxPixelRatio`, texture bütçeleri, `fixedStep` ve `maxFrameDelta` alanları constructor snapshot’ına bağlıdır; resmi `setLogicalSize()`/`setResizeMode()` yolları snapshot’ı günceller, doğrudan mutation `EXI_ENGINE_CONFIG` ile runtime girişlerinde reddedilir. Fallback sırasında yeni renderer aynı bütçeleri devralır.
Fiziksel canvas çözünürlüğü ile dünya viewport’u ayrıdır: `Camera.pixelRatio` 0.25..4 aralığında sınırlandırılır ve WebGPU GPU-culling uniform’larına da uygulanır; yüksek DPI değeri dünya alanını beklenmedik biçimde büyütmez.

`backgroundColor` yalnızca finite 24-bit renk değerine veya doğrulanmış `#rgb`/`#rrggbb` biçimine normalize edilir; `backgroundAlpha` 0..1 aralığına clamp edilir. `clearBeforeRender: false` uygulamanın bilinçli olarak önceki canvas içeriğine güvenmesini gerektirir ve varsayılan temizleme davranışını değiştirmez.

`Camera.follow()` hedef ve offset koordinatlarını finite değerlerle işler; geçersiz hedefler reddedilir, geçersiz takip koordinatı kameraya `NaN`/`Infinity` taşımaz.

`Camera.shake()` genliği 2.048, süresi 10 saniye ve frekansı 120 Hz ile sınırlar; geçersiz değerler shake’i iptal eder. Her frame önceki offset geri alınır, yeni offset bounded world değerleriyle yazılır ve `clearShake()` aktif offset’i bırakmadan temizler.

`Camera.setBounds()` yalnızca finite, pozitif dikdörtgen kabul eder; clamp hesabı zoom ve rotation görünür alanını hesaba katar ve aşırı küçük dünyalarda merkezi güvenli biçimde sabitler.

Tek bir render frame’inde fixed-step update sayısı 240 ile sınırlandırılır; arka plan sekmesi veya uzun stall sonrası biriken backlog tarayıcıyı kilitleyecek kadar büyüyemez.

`pauseOnHidden` varsayılan olarak açıktır: görünmez document engine RAF zincirini ve accumulator’ı durdurur, görünürlük geri gelince yeni zaman tabanıyla devam eder. Arka plan simülasyonu bilinçli olarak istenirse `pauseOnHidden: false` seçilebilir.

`timeScale` finite olarak 0..16 aralığında tutulur; doğrudan bozulmuş bir değer yazılsa bile her simulation adımında normalize edilir ve ölçeklenmiş delta `maxFrameDelta` tavanını geçemez. Bu, fast-forward seçeneğinin fixed-step catch-up sınırlarını aşarak CPU kilitlemesini önler.

`interpolate` yalnızca finite `0..1` render alpha’sı ile geçici transform değerleri üretir; render exception’ı dahil her yolun sonunda node transform’ları güncel oyun state’ine geri yüklenir. Interpolation snapshot’ları asset veya kullanıcı kodu çalıştırmaz ve varsayılan olarak kapalıdır.

`AssetLoader` image boyutu 16.384 px, texture pixel bütçesi 16 MiB ve response byte bütçesi 64 MiB mutlak tavanlarını uygular; bilinen PNG/JPEG/WebP/GIF/BMP header boyutlarını `createImageBitmap()`/`Image.decode()` öncesinde kontrol eder, decode sonrası ölçümü de tekrar doğrular. Constructor seçenekleri bu sınırları yükseltemez. `TextureAtlas` JSON/grid/pack yolları da frame, boyut ve pixel bütçelerini mutlak üst sınırlarla doğrular; `Infinity` gibi seçeneklerle bu kontroller aşılamaz.

`TextureAtlas.pack()` CanvasImageSource, `Texture` ve atlas subtexture kaynaklarının boyut/crop koordinatlarını doğrular; padding toplamı safe-integer/atlas boyutu kontrolünden geçer ve büyük safe-integer girdileri packing aritmetiğine sokulmaz.

`AnimatedSprite` constructor/setFrames girdilerini snapshot’lar; frame sayısını, frame rate’ini ve tek update adımını sınırlar. `gotoFrame()`/`update()` public `frames` dizisi doğrudan taşınsa bile frame limitini yeniden doğrular; sonsuz frame döngüsü veya `Infinity` zaman girdisi oluşamaz.

`Tween` hedef/değer/duration/delta girdilerini finite aralıkta tutar; easing ve completion callback’leri fonksiyon değilse reddeder.

`Animator` varsayılan olarak 4.096, mutlak olarak 65.536 aktif tween ile sınırlıdır. `add()` ve `update()` oluşturulmuş kapasiteyi, public `tweens` Set taşmasını ve doğrudan `maxTweens` mutasyonunu O(1) yeniden doğrular. Aynı tween tekrar eklenirse kapasite tüketmez; `remove()` ve tamamlanan tween temizliği slotu geri verir. Böylece oyun callback’lerinin kontrolsüz tween ekleyerek CPU/heap büyütmesi sınırlandırılır.

`ExiEngine({ animator })` yalnızca `update()` fonksiyonu taşıyan açıkça verilen animator’ı fixed-step başına bir kez çağırır; animator callback’leri engine runtime-error sınırı içinde çalışır. Animator ve physics birlikte verilirse sıralama deterministik olarak scene update, animator update, physics step ve `onUpdate` şeklindedir.

`CollisionWorld` spatial broadphase seçeneği hücre başına collider ve sorgu hücresi sayısını mutlak limitler; aşırı büyük collider/query alanları güvenli tam taramaya döner. `Collider`/`PhysicsBody` local `bounds` override’ı finite, pozitif ve 1.000.000 dünya birimi tavanlıdır; `oneWay` yalnızca doğrulanmış dört yön değerini kabul eder ve hareket yönü/başlangıç tarafı uygun değilse static/kinematic collider’ı solid solver’dan çıkarır. Yok edilmiş Node’a bağlı collider world’e eklenemez ve sorgu çıktısına sızmaz; yok edilmiş PhysicsBody bir sonraki physics step’inde world’den çıkarılır. Bounds değişince spatial index dirty olur ve sonraki sorguda güvenli biçimde yenilenir. `raycast()` yön, mesafe ve broadphase alanını finite/1.000.000 dünya birimi sınırında tutar. Generic hareketli collider için açık `syncCollider()`/`rebuild()` sözleşmesi korunur; `PhysicsWorld` kendi dynamic ve kinematic body hareketlerinde yalnızca ilgili collider hücrelerini incremental günceller, velocity’yi `maxSpeed` ile sınırlar ve grounded taşıma delta’sını dünya birimi tavanında tutar. Kinematic body’ler gravity/rigid-body impulse almaz; hızlı body’ler ince static/kinematic collider’ları geçemez.

`CollisionWorld({ autoSync: true })` bu explicit rebuild kuralını yalnızca opt-in kullanımda kolaylaştırır; sorgu başına collider sayısıyla orantılı stale-transform kontrolü yapar. Bu maliyet varsayılan hızlı yola eklenmez.

`PhysicsWorld` body sayısını 10.000 ile sınırlar; `step()`, `overlaps()` ve spatial sync girişleri public `bodies` Set’i doğrudan taşırılsa bile bu bütçeyi O(1) yeniden doğrular. Overlap output’u çağrı sahibinin verdiği/reused listeyle, delta’yı 0.25 saniye ve fixed substep sayısını 16 ile, gravity/velocity/position aritmetiğini finite ve 100.000 dünya birimi sınırlarıyla tutar; fizik solver’ı kontrolsüz typed-array veya recursive graph üretmez.
`PhysicsWorld({ autoSync: true })` statik/dinamik collider AABB’sini transform sürümünün yanında geometri değerleriyle de kontrol eder; sprite boyutu veya çizim/tile içeriği değiştiğinde stale broadphase kullanılmaz. Bu doğruluk için sorgu öncesi O(n) kontrol varsayılan hızlı yolda kapalıdır.

`SpriteBatch` spatial culling de sprite başına hücre sayısını mutlak limitler; hücreler nested numeric `Map` ile tutulur, string anahtar üretimi yoktur; aşırı geniş sprite’lar sınırlı fallback listesinde görünürlük kontrolünden geçer ve kontrolsüz hücre üretmez.

`Node.cullBounds` yalnızca açıkça verilen finite local dikdörtgeni subtree coarse-culling için kullanır; bounds dışı dal render queue’ya girmeden kesilir, bounds doğrulaması scene graph’a sınırsız metadata üretmez.

`Node.add()` yok edilmiş/cycle oluşturan node’ları ve parent başına 65.536 child üstünü reddeder. Doğrudan public `children` mutasyonu için update, interpolation, layout, world-matrix, render/hit-test ve destroy traversal’ları per-traversal stamp ile duplicate/cycle algılar; graph derinliği 1.024 ile sınırlıdır. `destroy()` edilmiş Node’lar scene graph’a yeniden eklenemez ve update callback’i çalıştırmaz; engine scene/overlay geçişleri yok edilmiş graph’ları reddeder. Böylece GPU/asset yaşam döngüsü bitmiş bir graph’ın yeni frame akışına yeniden sızması engellenir.

Renderer context/device loss hataları backend ve faz/reason bilgisiyle işaretlenir; WebGPU kaybı ve WebGL context-restore başarısızlığı `recoverable: false` olarak ayrılır. Engine’in `onStatus` gözlemcisi güven sınırının dışındadır: gözlemci exception’ı loss, fallback, restore veya teardown akışını kesemez.

Node alpha değerleri `[0, 1]` aralığına normalize edilir; parent alpha çocuklara `worldAlpha` olarak çarpılır ve regular/static/instanced render cache anahtarlarına dahil edilir. Sıfır alpha render queue’dan elenir; kullanıcı girdisiyle sınırsız renk veya GPU stream değeri üretilemez.

Node filtreleri yalnızca allowlist içindeki `grayscale`, `invert`, `brightness`, `sepia`, `contrast` ve `saturate` shader dallarına gider; filtre miktarı `[0, 1]` aralığına normalize edilir. WebGPU filtre uniform buffer’ı batch sayısına göre yeniden kullanılır ve 16 MiB ile sınırlandırılır; kullanıcı girdisiyle dinamik shader veya sınırsız GPU allocation oluşturulmaz.

`Node.clipRect`, `maskRect`, `cullBounds` ve `hitArea` constructor/setter yanında world update sınırında da finite, pozitif ve `MAX_WORLD_COORDINATE` ile bounded dikdörtgen olarak doğrulanır; doğrudan public alan mutasyonu allocation üretmeden normalize edilir veya reddedilir. `maskTexture` constructor/setter ve world update sınırında gerçek `Texture`/`RenderTexture` instance’ı olarak doğrulanır; inherited mask texture/rect argümanları da aynı kontrolden geçer. Yalnızca mevcut bind yolundan örneklenir, mask buffer’ı veya recursive pass allocation’ı oluşturmaz, aynı RenderTexture’ın source/target feedback loop’u her iki backend’de reddedilir.

TileMap CPU culling yalnızca kamera local AABB’sinin sınırlı satır/sütun aralığını tarar; aralık harita boyutlarına clamp edilir. `cullTiles: false` yalnızca performans tercihini değiştirir ve tile allocation limitini aşamaz. `instanced: false` regular render yolu item/positions/UV havuzunu bounded tile sayısı içinde yeniden kullanır.

`TileMap.setRegion()` bölge boyutu harita sınırlarına ve mevcut tile limitine clamp edilir; tüm tile index’leri doğrulanmadan hiçbir hücre yazılmaz.
`TileMap.getCollisionRects()` tile sayısı limitli grid üzerinde çalışır; yalnızca bitişik solid hücreleri birleştirilmiş rect olarak üretir. `createStaticBodies()` rebuild sırasında yeni body/node listesini doğrular, PhysicsWorld ekleme hatasında yeni parçaları temizler ve önceki body’leri geri yükler.

`SpriteBatch` toplam sprite sayısı da 100.000 ile sınırlandırılır; CPU quad, instanced stream, bounds ve spatial-culling girişleri render öncesinde public `sprites` dizisi doğrudan değiştirilse bile aynı limiti O(1) doğrular, bu nedenle kontrolsüz JavaScript/GPU belleği ayıramaz.
`SpriteBatch` animasyonu en fazla 4.096 frame, 240 FPS ve tek update’te 4.096 frame adımı kabul eder; frame listeleri aynı atlas/base texture ile sınırlıdır. `addAnimatedSprite()` frame değiştiğinde yalnızca mevcut batch cache’ini invalidate eder, her animasyon frame’i için yeni scene node veya GPU buffer oluşturmaz.
`SpriteBatch.addSprites()` tüm kayıtları önce normalize edip texture/sprite limitlerini doğrular; hata durumunda batch kısmen yazılmaz ve başarılı toplu ekleme yalnızca bir cache invalidation yapar.
`SpriteBatch.markDirty()` doğrudan değiştirilen sprite kayıtlarının cache/spatial index yenilemesini açıkça ister; çekirdek, public kayıtları her frame tarayarak öngörülemez O(n) maliyet eklemez. `setSprite()` normalleştirilmiş güvenli yolu kullanır.
`SpriteBatch` spatial visibility sorgusu kamera köşelerini bounded local cell aralığına çevirir; güvenli integer/aralık doğrulaması başarısız olursa mevcut full-scan fallback kullanılır, bu nedenle bozuk transform girdisi sınırsız Map traversal’ına dönüşmez.

Pointer cancel, blur, visibility ve pagehide yolları aktif pointer capture’larını bırakır; geçerli pointer ID’leri güvenli integer’a normalize edilir ve aynı anda en fazla 32 pointer state’i tutulur. Interactive capture/hover hedefleri pointer ID başına tutulur, touch release veya input state’inin frame sonunda düşmesiyle hover kaydı temizlenir, `onWheel` yalnızca scene hit-test ile seçilen oyun callback’ine gider ve frame sonunda convenience pointer ID’si aktif pointer state’iyle eşitlenir.

Kamera viewport/zoom/bounds, Node transform, Node `hitArea` ve Sprite geometri girdileri finite olmayan sayıları güvenli varsayılanlara dönüştürür veya reddeder; `Camera.bounds` doğrudan public alan mutasyonundan sonra `clampToBounds()` sınırında yeniden doğrulanır. `MAX_WORLD_COORDINATE` (1.000.000.000) finite ama aşırı büyük dünya değerlerine de üst sınır koyar. `Mat3` çarpım/dönüşüm ara sonuçları ve Graphics primitive vertex’leri taşma öncesi bounded olarak tutulur; `NaN`/`Infinity` GPU vertex akışına taşınmaz.

Graphics geometri komutları finite sayılara normalize edilir ve toplam komut sayısı 4.096 ile sınırlıdır; render ve bounds girişleri public `commands` dizisi doğrudan değiştirilse bile bu limiti O(1) yeniden doğrular, geçersiz veya sınırsız primitive akışı kontrollü biçimde reddedilir. Dirty rebuild yolu aynı render-item/positions/bounds belleğini yeniden kullanır; komut sayısı azalınca eski kayıtlar render listesinden çıkarılır.

`Graphics.polygon()` point listesi çift uzunlukta, en az üç noktada ve en fazla 256 noktada tutulur; koordinatlar world sınırına normalize edilir, ear-clipping üçgenlemesi komut ekleme anında bounded CPU işi olarak yapılır ve geçersiz/üçgenlenemeyen şekil reddedilir. Render frame’i yeni triangulation çalıştırmaz.

`ParticleEmitter({ gpuCulling: true })` yalnızca oluşturulmuş kapasite kadar 16-float GPU source kaydı üretir; WebGPU compute culling screen-space compact output’u oluşturur. WebGL2 aynı emitter’ı CPU instanced fallback ile işler; public particle dizisi doğrudan taşırılırsa her iki yol da kontrollü hata verir.

`RenderTexture` width/height değerleri integer 16.384 px ve toplam 16 MiB pixel bütçesiyle sınırlıdır; WebGL2 framebuffer tamamlanma durumu doğrulanmadan hedef cache’e alınmaz, WebGPU hedef texture’ı render-attachment, sampling ve gerektiğinde `COPY_SRC` kullanım bayraklarıyla oluşturulur. `captureFrame()` ayrıca grid’i 64×64 ve 4.096 hücreyle sınırlar, geçici hedefi her çağrı sonunda yok eder ve en fazla 16 KiB packed RGBA8 piksel döndürür; RuntimeAgent serializer bu çıktıyı 32 KiB inline binary ve 64 KiB result sınırlarıyla ayrıca sınırlar. `observe` operasyonu bu düşük çözünürlüklü veriyi text grid’e indirger ve ham bytes döndürmez. Resize sırasında yeni hedef kaynakları başarıyla oluşturulup doğrulanmadan eski framebuffer/texture silinmez; tahsis hatası mevcut çalışan hedefi bozmaz. `renderToTexture()` kamera viewport uyumsuzluğunu reddeder ve aynı hedefin aynı pass içinde örneklenmesini feedback loop olarak keser; cihazın daha dar texture limitine uymayan hedef kullanıcı girdisi hatasıdır, device-loss olarak işlenmez.

Renderer texture girişleri de yaşam döngüsünü doğrular: destroy edilmiş normal texture, atlas frame’i veya base texture GPU cache’ine erişemez, yeniden placeholder tahsis edemez ve `EXI_TEXTURE_INPUT` kodlu kontrollü TypeError ile reddedilir. Atlas frame’leri aynı base filter state’ini okur; bir frame’deki filter değişikliği kardeş frame’lerde ve iki backend’in ortak GPU residency’sinde tutarlı kalır. Atlasın dış base texture’ı yok edilirse atlas ilk `get()`/`getFrames()`/`has()` erişiminde lazy biçimde kapanır ve cache’lenmiş frame’lerini yok eder; atlas dış texture’ın sahipliğini almaz. Batch kuyruğundaki aynı kayıtlar çizimden önce elendiği için bu kontrol doğrudan renderer çağrılarını da kapsar.

`RenderGroup` yalnızca mevcut limitli `RenderTexture` hedeflerini kullanır; her görünür grup post-order sırayla bir offscreen pass’te çizilir, sonra ana pass’te tek quad olarak örneklenir. Grup hedefi aynı pass’in color target’ı veya mask texture’ı olarak görülürse feedback loop reddedilir. Grup `destroy()` çağrısı yalnızca sahip olduğu hedefi bırakır; dışarıdan verilen hedefin yaşam döngüsü kullanıcıda kalır. Grup çocukları ana pass’e doğrudan sızmaz; offscreen kök bayrağı bu sınırı renderer ve queue arasında açıkça taşır.

`RenderGroup.effects` en fazla dört allowlist filtresi (`grayscale`, `invert`, `brightness`, `sepia`, `contrast`, `saturate`) kabul eder. Ping-pong zinciri iki ara hedeften fazlasını oluşturmaz; ara hedeflerin toplamı grup başına 16 MiB pixel bütçesini aşarsa efekt kurulumu kontrollü `RangeError` ile reddedilir. Ara hedefler grup tarafından sahiplenilir ve `destroy()` sırasında bırakılır; effect pass’leri kaynak/hedef aynı olduğunda route oluşturmadığı için feedback loop üretmez.

`engine.prepare()` grup çocuk queue’larını ve tüm grup/ara RenderTexture bind’lerini yalnızca doğrulanmış mevcut hedefler üzerinden hazırlar; hazırlıkta da yeni sınırsız hedef veya shader türü oluşturulmaz. Görünür olmayan gruplar scene traversal görünürlük sınırı nedeniyle hazırlık listesine alınmaz.

WebGPU render sırasında oluşan `RangeError` kaynaklı vertex/instance/texture/GPU-culling limit ihlalleri de `EXI_RENDER_INPUT` olarak dışarı çıkar; bu doğrulama hataları GPU kaynaklarını topluca bırakıp cihazı kayıp ilan etmez. Gerçek queue/command/device hataları ayrı device-loss yolunda kalır.

WebGL2/WebGPU backend `init()` ortasında oluşan hata doğrudan renderer teardown’ını tetikler; buffer, listener ve device referansları yarım kurulum olarak tutulmaz. WebGL2 regular/instance/static buffer kapasite değişimleri yeni handle ve upload başarıyla tamamlanmadan eskisini silmez; hata durumunda yeni handle temizlenip çalışan buffer geri bağlanır. Teardown, worker/SSR gibi event API’si eksik hostlarda da method-level güvenli çağrılarla tamamlanır.

WebGPU’dan WebGL2’ye fallback sırasında yeni backend kurulmadan önce eski kayıp renderer bırakılır. Yeni backend de başlatılamazsa engine eski GPU device/context referansını canlı tutmaz ve `renderer` boş kalır; sonraki hata kontrollü `renderer-error` status’üne gider.

Overlay pass’i backend’in global clear ayarını değiştirmeden `load` ile ana canvas üzerine çizilir; overlay pointer hit-test’i önce çalışır ve pointer scope map’leri scene/overlay ayrımını korur. Overlay scene veya camera asset verisiyle kendiliğinden oluşturulmaz; sahiplik uygulamadadır.

`Node.setLayout()` kenar, offset, boyut ve anchor değerlerini finite/bounded biçimde normalize eder; layout traversal’ı yalnızca uygulamanın verdiği scene graph üzerinde çalışır. `ExiEngine` resize sırasında layout’u overlay viewport’unda tekrarlar, ana gameplay scene’inin transform’larını kendiliğinden değiştirmez.

Focus traversal görünür node’lar için en fazla 4.096 aday toplar ve `tabIndex` değerini `-1..32.767` aralığında tutar. `onKeyDown` yalnızca uygulamanın açıkça focusable yaptığı node/parent zincirine gönderilir; event nesnesi transient olarak yeniden kullanılır, `preventDefault()` native keydown’a ancak callback bunu istediğinde aktarılır. Key callback exception’ı engine’in `runtime-error`/stop sınırında kalır.

`NineSliceSprite` en fazla dokuz sabit quad üretir; border değerleri finite ve world limitleri içinde tutulur, hedef boyutu küçükse kenarlar orantılı sıkıştırılır, texture frame boyutu aşılırsa UV kenarları texture sınırına çekilir. Resize hesapları bounded scratch alanlarını yeniden kullanır; kullanıcı texture’ı veya shader’ı çalıştırılmaz ve dokuz parça mevcut batch/culling ve texture bütçelerine tabidir.

## Yeni özellik kuralı

`AssetLoader.loadMany()` aynı origin, byte limiti ve `AbortSignal` kurallarını korur; yalnızca izinli `texture`, `json`, `bytes`, `atlas` ve açık decoder adaptörü verilen `ktx2` türlerini yükler. Atlas entry’sinde `url` texture, `atlasUrl` JSON metadata olarak yine aynı `loadTexture()`/`loadJSON()` sınırlarından geçer. Genel response byte bütçesi varsayılan 16 MiB ve mutlak 64 MiB tavanlıdır. Manifest 4.096 kayıt, asset anahtarı 256 karakter ve tek response stream’i 16.384 parça ile sınırlıdır; çok sayıda küçük chunk byte bütçesini dolaylı olarak aşamaz. `AudioManager.load()`/`loadMany()` da `integrity` seçeneğini mevcut `AssetLoader.loadBytes()` SHA-256 doğrulamasına aktarır; hash geçmeden audio decode/cache başlamaz. Audio batch'i 4.096 kayıt, 16 worker, audio key/URL doğrulaması, `AbortSignal` ve aynı decoded PCM/voice bütçeleriyle sınırlıdır. Audio bus'ları yalnızca uygulama içi `AudioBuffer` ve sabit Web Audio düğümleriyle çalışır; uzaktan script veya shader çalıştırmaz.
`AssetLoader.loadJSON()` 4 MiB varsayılan JSON byte bütçesine ek olarak bounded metin taramasıyla düğüm ve derinlik sınırlarını `JSON.parse()` öncesi uygular; parse sonrası exact graph doğrulaması da korunur. Loader’ın image/texture/JSON/response limitleri constructor’da ayrılan kapasiteye bağlıdır; public limit alanlarının doğrudan yükseltilmesi reddedilir. Çağrı bazındaki `maxJSONBytes`, `maxJSONNodes` ve `maxJSONDepth` yalnızca loader’ın daha dar sınırına clamp edilir. Sınırı aşan değer döndürülmez ve loader cache’ine yazılmaz. Çekirdek streaming JSON parser vaat etmez; byte ve parse-öncesi token sınırı ana savunmadır.

`AssetLoader` texture cache’i varsayılan 256 texture ve 128 MiB pixel bütçesiyle sınırlıdır. `loadTexture()`/`loadKTX2()`/`cacheTexture()`/`release()` girişleri public `cache` Map’inin doğrudan mutasyonundan sonra entry ve pixel toplamını yeniden doğrular; `maxCacheTextures`/`maxCachePixels` kapasitesi de constructor’da ayrılan bütçeye bağlı kalır. Bütçe dolduğunda yeni texture sonuçları cache’e alınmaz; mevcut uygulama referanslarını sessizce yok eden otomatik eviction yapılmaz.

Asset bütünlüğü uygulamanın dağıtım manifestine bağlıdır: `loadBytes()`, `loadJSON()`, `loadTexture()` ve `loadKTX2()` için isteğe bağlı `integrity: "sha256-..."` Web Crypto ile doğrulanır. Integrity verilen texture/KTX2 sonuçları yanlış hash’in cache’te kalmaması için cache’e yazılmaz; `loadAtlas()` texture ve JSON metadata hash’lerini `integrity`/`atlasIntegrity` olarak ayrı alır. Desteklenmeyen algoritma veya bozuk hash biçimi reddedilir.

WebGL2/WebGPU renderer’ları varsayılan 128 MiB ve 4096 GPU texture kaynağı toplam bütçesi uygular; `maxTextureBytes` en fazla 512 MiB, `maxTextureCount` en fazla 4096 olabilir. Normal texture ve RenderTexture tahsisi bütçeye girmeden önce doğrulanır; atlas `baseTexture` frame’leri aynı GPU kaynağını paylaşır. Renderer’ın public texture ve cihaz-limit alanları constructor/device snapshot’ına bağlıdır; doğrudan büyütme `EXI_RENDER_CONFIG` ile reddedilir. Bütçe hatası `EXI_TEXTURE_BUDGET` ile kontrollü input hatası olarak bildirilir, device/context loss sayılmaz.

`AssetLoader.destroy()` pending fetch controller’larını iptal eder ve geç dönen byte/bitmap sonuçlarının yok edilmiş engine cache’ine yazılmasını engeller; aynı byte/texture yüklemesi için farklı `AbortSignal` kullanan çağrılar tek bounded fetch/decode işini paylaşır, caller abort’u yalnızca ilgili promise’i reddeder ve ortak underlying request’i kesmez. `clear()` bilinçli olarak yalnızca cache neslini değiştirir. `AudioManager` de pending decode sonuçlarını engine teardown veya tekil `unload()` sonrasında geçersiz sayar; aynı isim/URL için farklı integrity isteklerini paylaşmaz ve doğrulama geçmeden decode etmez; böylece eski veya doğrulanmamış ses buffer’ı tekrar cache’e yazılamaz.

`AudioManager.loadMany()` içindeki abort, çalışan caller promise’lerini bekletmeden reddeder; `load()` aynı anahtar için pending byte/decode işini paylaşır, ortak `AssetLoader` işi caller signal’ı ile iptal edilmez ve yalnızca ilgili caller promise’i reddedilir. Batch worker sayısı bounded tutulur. Decode tamamlanırsa sonuç yalnızca manager/key generation geçerliyse cache’e yazılır.

`inspectKTX2()` ve `loadKTX2()` KTX2 identifier, 2D/face/layer/depth, mip sayısı, 64-bit level/metadata aralıkları, pixel ve uncompressed byte bütçelerini decoder çalışmadan önce doğrular. Çekirdek yalnızca uncompressed RGBA8 KTX2 yolunu doğrudan oluşturur; Basis/ETC1S/UASTC/Zstd decoder’ı uzaktan veya asset içinden kendiliğinden yüklenmez, yalnızca uygulamanın açıkça verdiği bounded decoder callback’i çalıştırılır.

`AudioManager` aktif Web Audio source node’larını varsayılan 64, mutlak 256 voice ile sınırlar; tek audio response 64 MiB, toplam decoded PCM 512 MiB tavanına sahiptir. `maxBytes`, `maxDecodedBytes` ve `maxVoices` constructor snapshot’ına bağlıdır; doğrudan büyütme `EXI_AUDIO_CONFIG` ile reddedilir. `ended` callback’i voice kaydını bırakır; `stopVoice()`/`stopAll()` ve `unload()` ilgili source’ları durdurup referanslarını temizler. Voice limiti decoded PCM bütçesinden bağımsız ikinci bir canlı-node/CPU maliyet sınırıdır.

`AudioManager.play()` ve `setVoicePan()` içindeki pan değeri `-1..1` aralığına clamp edilir; `setVoiceVolume()` de volume’u `[0,1]` aralığında tutar. Varsayılan merkez pan ek `StereoPannerNode` oluşturmaz; yalnızca merkez dışı değerlerde panner graph’a lazily eklenir, merkeze dönüşte ve voice durduğunda disconnect edilerek temizlenir. Panner desteği olmayan tarayıcı kontrollü hata döndürür.

Audio bus mute durumu ayrı tutulur: `setBusMuted()` gain node’unu geçici olarak 0’a çeker, `setBusVolume()` sessiz bus’ın hedef volume değerini günceller ve unmute gerçek son değeri geri yükler. `fadeBus()` native AudioParam automation kullanır, süreyi 60 saniyede sınırlar ve yeni direct/mute/fade çağrılarında eski schedule’ları iptal eder. Böylece mute/unmute ve menü müzik geçişleri ses ayarını veya sınırsız automation event’ini biriktirmez.

`AudioManager.suspend()`/`resume()` yalnızca mevcut AudioContext’i kontrol eder; context yaratıp autoplay politikasını aşmaya çalışmaz. `ExiEngine.pauseAudio` varsayılan olarak açıktır ve engine’in kendisinin durdurduğu çalışan context’i görünürlük/manuel resume sırasında geri açar; zaten suspended olan context’i sahiplenmez. `pauseAudio: false` seçeneği ses yaşam döngüsünü uygulamaya bırakır.

Yeni bir loader veya plugin; kaynak allowlist’i, byte limiti, parse doğrulaması, abort desteği ve kötü içerik durumunda güvenli hata davranışı olmadan çekirdeğe alınmaz. Her non-trivial güvenlik yolu en az bir runnable smoke test ile korunur.

Graphics ve particle API’leri yalnızca sayısal geometri üretir; shader veya script metni kabul etmez. Particle havuzu `maxParticles` ile sınırlıdır ve frame başına sınırsız kaynak ayırmayı hedeflemez.

RuntimeAgent ve MCP `inspect` yalnızca object prototype üzerindeki engine method’larını callable kabul eder. Instance üzerindeki `onUpdate`, `onRender`, `onStatus` ve benzeri oyun callback’leri agent method listesine alınmaz ve `exi_call`/runtime `call` üzerinden çalıştırılamaz; gameplay callback’leri yalnızca proje dosyalarında insan/agent review’undan sonra çalışır.

Callback isteyen API’ler için tek istisna, browser sayfasının önceden `RuntimeAgent({ callbacks })` ile kaydettiği fonksiyonun JSON’daki `{"$callback":"name"}` referansıyla seçilmesidir. MCP callback gövdesi, closure veya function source taşımaz; `eval`/`new Function` yoktur. Registry 256 callback ve isim başına 256 karakterle sınırlıdır, bilinmeyen isim kontrollü hata verir ve callback sonucu mevcut bounded RuntimeAgent serializer’ından geçer. Bu güvenli seçim katmanı sandbox değildir; proje dosyaları yine trusted agent/review sınırında tutulmalıdır.
### MCP optimistic file versions

`exi_file_read`/`exi_file_list` ve `exi_asset_read`/`exi_asset_list` yalnızca `{ bytes, mtimeMs }` version metadata’sı döndürür. Agent bu değeri `expectedVersion` olarak `exi_file_write`, `exi_file_begin`, `exi_asset_write`, `exi_asset_begin` veya `exi_project_apply` çağrısına verebilir; mevcut dosya değişmişse işlem `EXI_MCP_FILE_CONFLICT` ile reddedilir. Chunk commit hedefi tekrar kontrol eder ve stale upload’ı hedefe taşımaz. Bu mekanizma optimistic concurrency guard’dır, filesystem lock değildir; son kontrol ile rename arasındaki dış yarış penceresi açıkça kabul edilir.
### Upload integrity guard

`expectedSha256` isteğe bağlı bir içerik bütünlüğü kontrolüdür; yalnızca 64 hexadecimal SHA-256 digest kabul edilir. Direct text/asset writes hash’i temporary-file rename’inden önce, chunk uploads ise incremental hash’i commit’ten önce karşılaştırır. Uyuşmazlıkta `EXI_MCP_UPLOAD_INTEGRITY` döner ve hedef dosya değiştirilmez. Bu kontrol MCP’nin trusted-local-process sınırını sandbox’a dönüştürmez.
