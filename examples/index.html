ExiEngine examples

Small, complete games that use only src/index.js. Run npm run dev and open them from here.

  • Platformer — Tiled map import, tile collision bodies, gravity, jump buffering, camera follow with bounds, HUD overlay.
  • Top-down arena — axis input, static wall bodies, trigger pickups, A* chasing enemies, particles, camera shake.
  • Normal-mapped lighting — LightLayer with a normal buffer: generated brick and orb normal maps, a torch on the pointer, toggling normal maps and light height.
  • Physics sandbox — RigidBodyWorld: boxes, circles and convex polygons with rotation, friction, restitution; a standing pyramid, a joint bridge, pendulum, motorized windmill and piston; click to drop shapes.
  • UI widgets — Button, Slider, TextInput (IME/mobile through a hidden input), ScrollView, Checkbox, Dropdown and Stack with pointer, wheel and keyboard focus.
  • UI menu — overlay scene, pointer and keyboard focus, tweened buttons, StateMachine screens, responsive layout.
